## 🇬🇧 English Version

### 📌 Overview
**PC Optimizer & Drive C Manager** is a high-performance Windows Desktop Application built with Electron and Node.js. It helps users free up C Drive storage, clean system junk, optimize RAM/CPU for specific workflows (Video Editing & AI Coding), and safely manage active processes with an intuitive Cambodian/English interface.

---

### ✨ Key Features

1. 📂 **Drive C Storage Manager & Safe Migration:**
   - Real-time disk space usage monitor for drives (C:, D:, F:).
   - Instant temporary and junk file cleaner (`Windows\Temp` & `User Temp`).
   - Non-destructive migration of user folders (`Downloads`, `Desktop`, `Videos`, `Pictures`, `Documents`, `Music`) from Drive C to Drive D/F via Robocopy.

2. ⚡ **Workflow Performance Boosters:**
   - **🎬 Video/Photo Edit Mode:** Terminates resource-heavy background bloatware (Google/Edge Updaters, OneDrive, Telemetry, Xbox DVR, Films & TV) to maximize RAM/CPU for NLEs & graphics tools.
   - **💻 Coder & AI Mode:** Optimized for developer environments (Antigravity IDE, Claude AI, Gemini, VS Code, Node.js) while **preserving custom tools like `AutoClickerPC`**.

3. 📋 **Smart Process Manager & Bulk End-Task:**
   - Monitors top 80 memory-consuming processes.
   - Detailed process descriptions and role explanations under each item.
   - **Categorized Badges:** 🔴 *Bloatware*, 🟢 *Safe to End*, 🛡️ *System Protected*.
   - **Bulk "End All" Button:** Allows instant one-click termination of bloatware or safe categories with safety shields preventing system crash.

4. 🚀 **Lightning-Fast Instant Launch (<1s):**
   - Embedded in-process server architecture providing instant application launch (<1s startup).
   - Native Windows System Tray integration and automatic Administrator elevation.
